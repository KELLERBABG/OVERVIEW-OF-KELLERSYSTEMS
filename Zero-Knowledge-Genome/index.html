1.0 Purpose

Direct-to-consumer genomic testing stores whole exome or microarray files on corporate cloud servers. That creates three exposures at once: a subpoena reaches the file, an insurer can infer from it, and the leak is irreversible because a genome cannot be reissued.

Once a relative has been sequenced, kinship correlation identifies people who never took a test. Consent is not a control on that; it belongs to someone else's file.

ZKG inverts the arrangement. The sequence becomes a set of client-side cryptographic commitments, and what leaves the machine is a proof about one predicate: carrier status, an HLA match, or a metaboliser phenotype.

The verifier learns one bit, and the sequencer's signature. It does not learn the locus next door, and it cannot walk the genome.

2.0 Method

An accredited sequencing facility signs a Poseidon Merkle root over the patient's authenticated variant array. Each leaf is one variant, so the root commits to the whole file without publishing any of it. The client proves membership in that root and evaluates a boolean condition on the leaf it selected.

// one variant, committed
Leaf_i = Poseidon(RSID_i, Chr, Pos, Allele_A, Allele_B, Blinding)
Root   = MerkleRoot([Leaf_0, Leaf_1, ... , Leaf_n])
// the sequencer's signature is verified inside the SNARK

// the predicate, compiled per question
template SnpPredicateVerify(merkle_depth) {
  signal input root;
  signal input rsid;
  signal private input path[merkle_depth];   // never leaves the client
  signal output is_carrier;                  // the only thing revealed
}

4.0 Withheld

What this does not claim, stated as plainly as the rest.

  • The lab is still trusted. The root is signed by an accredited facility, so the proof is only as good as that attestation. ZKG removes the database from the trust path; it does not remove the sequencer.
  • A proof is one predicate wide. Every question costs a circuit and a proof. That is the privacy guarantee and also the reason this cannot answer open-ended queries over a genome.
  • The parameters are the project's own benchmarks. Witness generation at 1.24 s, a 128-byte proof and roughly 210k gas are measured on the reference implementation, not audited by a third party.
  • Nothing here has been through a security review. Groth16 over BN254 is well studied; this implementation of it, and the circuits compiled for each predicate, have not been.
