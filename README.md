## 🔄 Updating & Synchronization

To synchronize all local project edits from `SYSTEMS & CREATIONS` into this overview repository at any time:

```powershell
# From the SYSTEMS & CREATIONS directory:
.\Sync-Overview.ps1
```

The script automatically:
1. Mirrors the latest code across all 36 repositories.
2. Strips out build caches (`target/`, `.venv/`, `.keller/`, binaries).
3. Re-calculates language percentages for Rust, Python, C, and all other languages.
4. Updates this `README.md` with new metrics.
5. Commits and pushes the updates directly to GitHub.
