Basics

What is audio watermarking?

Audio watermarking embeds a keyed identifier into the audio signal itself, so the ID can be recovered after some processing. Aureal carries a 32-bit ID plus a CRC using direct-sequence spread spectrum, with a frame of about one second. A match is a provenance signal, not proof of authorship or ownership.

Technical basis: Direct-sequence spread spectrum, 32-bit payload, CRC-16 Reviewed: 2026-11-02

How Aureal handles it

Aureal spreads 48 BPSK symbols across a frame of about one second using a key-derived pseudorandom sequence. It can use the high band (17–19.5 kHz), the mid band (4.5–13.5 kHz) or both. Detection folds repeated frames, searches for the key-derived chirp preamble, and reports a 32-bit ID with a CRC check. The embedding level is intentionally low; audibility is material-dependent.

Common failure mode

“A watermark is a hidden metadata tag that proves who owns the file.”

Why it fails: The statement confuses an embedded signal with a container tag and with an ownership proof. The ID lives in the audio samples, and a match identifies a copy; anyone with the software and the matching key can generate a matching ID.

Verified example

Treat the recovered ID as a distribution pointer:
1. Match it to your recipient manifest.
2. Keep the original, the marked copy and the detection report.
3. Use contracts and cryptographic signing for ownership records.

Example only. Validate against your own audio, codec and processing chain.

Scope and limits

  • A match is not proof of authorship, ownership or creation time.
  • Audibility varies with material, strength, carrier band and playback.
  • Recovery depends on source audio, codec and processing.

Frequently asked questions

Is the watermark inaudible?

It is designed to be subtle. Audibility varies with the source material, strength setting, carrier band and playback system; it is not a guarantee of inaudibility.

Does a match prove I own the audio?

No. A match identifies a copy that carries the ID. Ownership and authorship need independent records, contracts or cryptographic signing.
