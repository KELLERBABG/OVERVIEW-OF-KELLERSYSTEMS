Basics

The 32-bit payload and the key: how Aureal IDs work

The 32-bit ID is a lightweight pointer, not a metadata container. Detection needs the same key used for embedding. Re-marking the same audio with the same key and a conflicting ID can destroy the original ID, so use a fresh copy per recipient, a private key and a manifest.

Technical basis: 32-bit payload, keyed PN sequences, ~1 s frame Reviewed: 2026-11-02

How Aureal handles it

Aureal packs a 32-bit payload plus a 16-bit CRC into 48 BPSK symbols per frame. The spreading sequence is derived from the key, so detection without that key is not the supported path. The built-in default key is a public constant for demos; production use should generate a private key. Keep the key out of the distributed audio and in your own records.

Common failure mode

“Re-mark the same master with the same key and a new ID for each recipient.”

Why it fails: Same-key overwrite collisions cause destructive bit interference. Reusing one key with conflicting IDs on the same master is not a safe way to issue per-recipient copies, and losing the key can make recovery impossible.

Verified example

Use a private key and a fresh ID per distribution copy:
- Generate a unique 32-bit ID for each recipient.
- Keep the key and the recipient manifest under your control.
- Do not re-mark the same master with the same key and a conflicting ID.

Example only. Validate against your own audio, codec and processing chain.

Scope and limits

  • Detection requires the same key used for embedding.
  • The built-in default key is public; use a private key.
  • Same-key overwrite with a conflicting ID can destroy the original ID.

Frequently asked questions

How many IDs are available?

The payload is 32 bits, so there are 4,294,967,296 possible IDs. Treat the ID as a pointer and keep a manifest; collisions and reuse are an operational risk.

What happens if I lose the key?

You may not be able to recover the ID reliably. Keep the key with the distribution records and use a private key, not the public default.
