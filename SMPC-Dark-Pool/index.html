01 — the splitZero information, not merely encrypted

A centralised dark pool still has an operator, and the operator can read the book. Encrypting it moves the problem rather than solving it, because whoever holds the key can read it too.

Shamir secret sharing removes the key. An order becomes a set of linear polynomials over a prime finite field, and any subset smaller than the threshold possesses zero information — not impractical to read, but information-theoretically nothing. Seven shares, five required: any four reveal as much as four random numbers.

02 — the matchArithmetic on values nobody sees

Matching is the hard part, because comparing two prices usually means knowing them. Beaver triples let the nodes multiply secret shares without reconstructing anything, so cross-order volume clearing happens entirely in encrypted space. A blind equality check answers the only question that matters — is the best limit buy at or above the best limit sell — and returns one bit.

Solvency is proved rather than asserted: a trader demonstrates escrowed collateral sufficient to back an order without revealing a wallet balance or a portfolio size.
