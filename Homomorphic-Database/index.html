LAYER 01

BGV / BFV Exact Relational Algebra

LAYER 02

CKKS Fixed-Point Analytics & ML

Encrypted float vectors enable complex statistical aggregations (standard deviation, linear regression, neural inference) without loss of precision.

ckks::mult_and_rescale(&c_vec, scale_factor)
LAYER 03

TFHE Fast Boolean Gate Bootstrapping

For arbitrary nonlinear logic gates (AND, XOR, MUX), TFHE provides sub-10ms programmable bootstrapping that resets noise budgets indefinitely.

tfhe::bootstrap_gate(c_bit_a, c_bit_b)
LAYER 04

SIMD Slot Packing & Batching

Pack up to 4,096 scalar records into a single Ring-LWE ciphertext polynomial, parallelizing SQL filtering operations across thousands of rows per CPU instruction.

packing::simd_pack_batch(&records)
LAYER 05

Relinearization & Key-Switching

Quadratic tensor product expansion during ciphertext multiplication is compressed back to linear size using public relinearization evaluation keys.

relinearize(&c_prod, &eval_key)
