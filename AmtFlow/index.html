AmtFlow ist ein datenschutzfreundlicher Public-Good-Assistent für amtliche Bescheide und behördliche Korrespondenz. Er analysiert Bescheide via lokaler Browser-OCR, berechnet gesetzliche Rechtsbehelfsfristen (§ 70 VwGO), übersetzt Beamtendeutsch in 30 Sprachen und erstellt formgerechte DIN 5008 Widerspruchsschreiben ohne Cloud-Transfer.

On-Device Dokumentenanalyse

Sensible behördliche Bescheide (Jobcenter, Finanzamt, Ausländerbehörde) enthalten vertrauliche personenbezogene Daten, die niemals an externe Cloud-Server hochgeladen werden dürfen:

const metadata = await amtflowCore.analyzeDocument(documentImage, { extractLegalDeadlines: true, targetLanguage: 'de-easy', // Leichte Sprache }); // Erkennt Absender, Aktenzeichen und Rechtsbehelfsbelehrung offline im Browser

DIN 5008 Antwortschreiben per Knopfdruck

Generiert rechtssichere Vorlagen für Fristverlängerungen, Widersprüche und Nachreichung von Unterlagen im exakten deutschen Briefformat (DIN 5008 Form A/B):

const replyLetter = amtflowCore.generateReply({ caseNumber: metadata.aktenzeichen, authority: metadata.behoerde, action: 'FRISTVERLAENGERUNG', requestedDays: 14, });
