# SmokeShift Tracker

**Domain:** Worker Safety / Climate — literally separate
**One-liner:** Clip-on PM2.5 dose tracker for outdoor crews. Warns when shift dose exceeds limit, logs for employer liability.

**Buyer:** Construction, forestry, road crews, unions (2026 wildfire smoke regs)
**Why easy to sell:** OSHA/EU tightening smoke rules, employers need proof of protection. Device 49 EUR.
**Tech:** Nordic nRF52 + Sensirion SPS30 + BLE to phone, not FHE, not ZK.
**Not developed:** Air quality monitors exist, not shift-dose + worker log.
**Standalone:** Wearable safety.
