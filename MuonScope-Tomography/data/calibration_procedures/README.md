# MuonScope Calibration Procedures & Checklists

This directory contains standardized calibration sequences and automated scripts:

1. **`01_sipm_dac_trim.md`**: Step-by-step procedure for active SiPM overvoltage calibration and 1 p.e. dark count equalization.
2. **`02_tdc_vernier_deskew.md`**: Protocol for carry-chain TDL timing delay deskewing across all 128 channels.
3. **`03_astm_monthly_audit.md`**: ISO 9712 monthly verification run against the physical $500\text{ mm}$ ASTM calibration cube.
4. **`04_imu_coordinate_alignment.md`**: Dual-antenna RTK-GNSS and 9-DoF IMU coordinate frame transformation alignment guide.
